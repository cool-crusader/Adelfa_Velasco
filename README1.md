# Finding The Hypotenuse

## Description
A short program where it calculates a triangles hypotenuse (Pythagorean Theorem) using the numbers the user inputs. 

## Input Needed
Enter the following values
asquared and bsquared
## How to run
- Copy the link to your GitHub repository.
- Submit the repository link in KHub for marking.
- Make sure the repository is accessible and contains the correct files before submitting
- On the top right part of the program, click the run (or play) button
- Ta-Da!
## Sample Output
a = `What the length of side a: 6`\
b = `Enter the length of side b: 8`\
Output: `The hypotenuse is: 10.00`\
